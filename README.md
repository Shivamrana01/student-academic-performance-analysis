## 📌 About the Project

**Student Academic Performance Analysis** is a beginner-friendly Education Analytics project developed to explore patterns in student marks, attendance, and study habits.

Using Python and data analysis libraries, this project compares subject-wise performance, calculates descriptive statistics, and examines the relationships between attendance, study hours, and average marks.

The goal is to demonstrate how data analysis can help educators identify areas where students may benefit from additional academic support.

## 🎯 Project Objectives

- Analyze student marks using descriptive statistics.
- Calculate mean, median, and pass percentage.
- Compare performance across Maths, Science, and English.
- Explore the relationship between attendance and average marks.
- Examine the association between study hours and marks.
- Create clear visualizations to communicate findings.
- Present evidence-based recommendations for academic support.

## 📂 Dataset Information

This project uses **10 synthetic student records** created for educational purposes. No real student information is used.

| Column | Description |
|---|---|
| `Student_ID` | Anonymous student identifier |
| `Maths_Marks` | Mathematics marks |
| `Science_Marks` | Science marks |
| `English_Marks` | English marks |
| `Attendance` | Attendance percentage |
| `Study_Hours` | Daily study hours |

**Assumption:** A score of 40 or above is treated as passing for this project.

## 🔍 Project Workflow

1. **Data Creation:** Create a sample dataset using Pandas.
2. **Descriptive Statistics:** Calculate mean, median, and pass percentage.
3. **Subject Comparison:** Compare average marks across subjects.
4. **Data Visualization:** Generate bar charts and box plots.
5. **Correlation Analysis:** Calculate Pearson correlation coefficients.
6. **Relationship Analysis:** Create scatter plots for attendance, study hours, and average marks.
7. **Data Cleaning:** Check missing values, duplicate records, and invalid values.
8. **Final Insights:** Summarize findings and suggest possible academic support measures.

## 📊 Visualizations

The project includes the following visualizations:

- 📊 **Bar Chart:** Average marks by subject.
- 📦 **Box Plot:** Distribution and spread of subject marks.
- 📈 **Scatter Plot:** Attendance versus average marks.
- 📈 **Scatter Plot:** Daily study hours versus average marks.

These visualizations make it easier to compare subjects and observe patterns in the sample data.

## 💡 Key Findings

Based on the project's synthetic dataset:

- Science has the highest average marks among the three subjects.
- Maths has the lowest average marks in the sample.
- Attendance and study hours show positive associations with average marks.
- Subject-wise statistics help highlight differences in performance.

*Refer to the executed notebook for exact numerical results and correlation coefficients.*

## 🧠 Conclusion

This project demonstrates how Python-based data analysis can be used to explore student academic performance.

Descriptive statistics summarize marks, visualizations compare subjects, and correlation analysis examines associations between attendance, study habits, and average marks.

The findings illustrate how such analysis may guide further investigation and academic support planning. However, correlation does not prove causation, and results from a small synthetic dataset cannot be generalized to real students.
